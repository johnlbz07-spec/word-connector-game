# Misi Kata Hubung

Permainan ini adalah versi web game bahasa Melayu yang bertemakan cerita dan cabaran level seperti "闯关".

## Ciri-ciri
- 6 bab / level dengan cerita
- Soalan kata hubung dalam ayat
- Sistem skor, nyawa, dan hint
- Antara muka yang interaktif dan mudah digunakan
- Boleh dimainkan terus di browser

## Cara main
1. Buka fail `index.html` di browser.
2. Tekan butang "Mulakan Petualangan".
3. Jawab semua soalan dengan betul.
4. Kumpul skor dan selesaikan semua bab.

## Struktur fail
- `index.html` - struktur utama game
- `style.css` - reka bentuk dan tema permainan
- `script.js` - logik permainan, soalan, dan level

## Optional: jalankan melalui server tempatan
Jika anda mahu membukanya dengan cara yang lebih stabil:

```bash
python -m http.server 8000
```

Lepas itu buka:

```text
http://localhost:8000
```

## Tujuan projek
Membina permainan pembelajaran kata hubung yang lebih menarik, interaktif, dan berkonsepkan storyline dengan elemen seperti cabaran level.
